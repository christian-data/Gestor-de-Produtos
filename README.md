
# 📦 Gestor de Produtos

Aplicação desktop desenvolvida em Python para gerir
produtos através de uma interface gráfica simples.

## 🚀 Funcionalidades

- Registar produtos com nome e preço
- Visualizar a lista de produtos
- Editar informações dos produtos
- Eliminar produtos
- Armazenar informações numa base de dados SQLite

## 🛠️ Tecnologias utilizadas

- Python
- Tkinter / ttk
- SQLite

## 💻 Sobre o projeto

Este projeto pessoal foi desenvolvido para praticar
programação em Python, criação de interfaces gráficas
e integração com bases de dados.

A aplicação utiliza Tkinter para a interface gráfica
e SQLite para armazenar as informações dos produtos.

## 📚 Aprendizagens

Durante o desenvolvimento, pratiquei:

- Programação em Python
- Desenvolvimento de interfaces gráficas
- Operações com bases de dados
- Organização e manutenção do código
- Resolução de problemas
